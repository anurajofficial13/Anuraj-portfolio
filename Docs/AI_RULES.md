# AI Rules

- Improve existing code only.
- Never redesign unless asked.
- Preserve UI, architecture, responsiveness, animations, and performance.
- Existing project is the source of truth.
- Use attached CV for content.
- Never invent experience, projects, skills, statistics, testimonials, or certifications.
- Keep React + Vite + Tailwind.
- Reuse existing components and hooks.
- Keep folder structure.
- Use local assets only; no stock images unless requested.
- Use functional components and React hooks.
- Keep code clean, modular, and reusable.
- Remove unused code/imports only if safe.
- Do not modify unrelated files.
- Keep accessibility and SEO intact.
- If information is missing, leave a TODO instead of guessing.
- Verify `npm run build` succeeds before considering the task complete.
